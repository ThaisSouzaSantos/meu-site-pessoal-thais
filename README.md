# Meu Site Pessoal

## Trabalho de engenharia de Software
Desenvolvimento de uma página pessoal estática publicada no GitHub Pages, desenvolvida como atividade prática de Git, 
GitHub e revisão de código em duplas.
______________________
### Sobre o projeto

O objetivo deste projeto é praticar o fluxo de trabalho profissional de desenvolvimento colaborativo:

- controle de versão com Git
- uso de branches para isolar funcionalidades
- abertura e revisão de Pull Requests
- code review com a ferramenta do GitHub
- deploy automático com GitHub Pages
